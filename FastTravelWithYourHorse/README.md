# Fast Travel with your Horse

***Note: This mod has only been tested in local multiplayer.***

Tired of leaving your horse behind when fast traveling? This mod checks if your horse is nearby when you board a minecart (or the parrot express on Ginger Island) and transports it right to your side upon arrival.

This mods supports [Integrated Minecarts](https://www.nexusmods.com/stardewvalley/mods/11881) and [Beach Minecart](https://www.nexusmods.com/stardewvalley/mods/13650).

## Known issues

The mod scans adjacent tiles to find an open spot for your horse upon arrival. If every nearby tile is blocked by objects or decorations, the horse will be forced to spawn inside a nearby decoration.

## Configuration

You can toggle minecarts and parrot express individually, as well as toggle indoors locations, by editing the `config.json` file in the mod folder, or by using [Generic Mod Config Menu](https://www.nexusmods.com/stardewvalley/mods/5098) in-game.

## Language support

This mod is machine-translated into all in-game languages. If you have suggestions for better wording, please let me know in the Posts tab.

## Installation

1. Install the latest version of [SMAPI](https://www.nexusmods.com/stardewvalley/mods/2400).
2. Download this mod and unzip it into your `Stardew Valley/Mods` folder.
3. (Optional) Install [Generic Mod Config Menu](https://www.nexusmods.com/stardewvalley/mods/5098) to change settings directly in-game.
4. Run the game using SMAPI.
